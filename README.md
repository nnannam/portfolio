# Портфолио Анны Масловой

Локальная адаптивная вёрстка по макету Figma. Все изображения и шрифт хранятся в assets, внешние загрузки не нужны.

Откройте index.html в браузере или запустите из этой папки:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Затем откройте http://127.0.0.1:4173.

Состав: index.html — контент; styles.css — оформление и адаптация; script.js — подсветка текущего раздела.

Навигация по странице работает. Карточки проектов и контакты пока представлены без внешних ссылок; кнопка резюме отключена. Их подключение отложено по договорённости. Контактные данные перенесены с макета, перед публикацией стоит сверить их написание.
